# Channel Continuity Python adapter

`channel-continuity` provides the `channel_continuity` event codecs and a
LiveKit Agents adapter in `channel_continuity.native`. In the demo, the adapter
hands a scoped text or voice turn to the gateway for durable acceptance before
starting a reply.

See the repository’s [architecture guide](../../../docs/architecture.md) for
the adapter’s role in the end, SMS, and rejoin sequence.
