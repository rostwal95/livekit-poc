# Agent Continuity

`agent-continuity` provides the `continuity_lab` Python interfaces for durable
cases, confirmation, leased execution, and result delivery. The portfolio demo
uses its PostgreSQL backend through `case_control_api`, `postgres_api`,
`work_api`, and `execution_api`.

See the repository’s [architecture guide](../../../docs/architecture.md) for
the storage and process boundaries, and the [demo walkthrough](../../../docs/demo.md)
for a concrete operator example.
