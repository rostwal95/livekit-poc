P2 opens a fresh verified interaction after a room closes, restoring authoritative
case facts/current revision, bounded relevant accepted history, pending original
work references and separately attributed communication evidence. A new room is
not a new business case; an old room, carrier account or familiar phone number is
not current account authorization. Historical read/replay APIs retain their old
meaning. A new current-grant-gated read-only facade supplies rehydration. It creates
zero new accepted inputs, operations, confirmation, sends, effects or generation.
A later new accepted user input demonstrates useful native continuation separately.

P3 turns the previously qualified libraries and private qualification approach
into a maintained reproducible standalone build/install/example command. Fresh
P1/P3 wheel/sdist/rebuilt and applicable npm artifacts are consumed through public
installed imports. The public completion example actually runs against the local
specialist, receiver and exact separately supplied confirmation. Fresh-process
replay preserves original facts and adds no new invocation/delivery/effect. Keep
owner bootstrap/worker test instrumentation distinct from the public consumer.

## Interfaces and ownership

P2 owns typed rehydration contracts, current-grant facade/P2 snapshot store,
standalone and existing public-P1 read adapters, optional Python context loader,
project fixtures/tests/examples and project guides. Preserve the old inbox/history
and v7 evidence APIs. Prefer no schema change when existing v7 state suffices;
any new persisted state requires explicit owner versioning before serving.
Scope derives from trusted current native binding or original accepted-SMS sender
and current association, never arbitrary body case/account labels.

P2 and authoritative case reads are separately observed. The facade first reads
an authorized coherent P2 section, calls a narrow read-only case port outside SQL,
then performs a fresh protected current-permission check before disclosure. Freeze
exact observation/expiry/lock semantics, closed fields, original identity joins,
cursor/truncation rules and one total UTF8 snapshot cap before implementing this
boundary. Native model context must label history as untrusted data and never gain
confirmation/quote/mutation tools. New-room facts retain original bindings and IDs.

P3 owns the maintained standalone package driver, configured public consumer,
unadapted public completion/metadata example invocation, specialist/owner fixtures,
focused tests and five guides. P1's 77 and P3's 30 production payloads, existing
public APIs and storage remain unchanged unless a reviewed concrete gap proves
otherwise. Build a fresh P1 dependency wheel instead of referencing a prior local
UUID or private script. Label supported host/platform and installed proof scope.

Root owns this work item, independent protocol review, UI/context presentation and
actual P2 storage/media orchestration, Make/discovery/shared docs and checkpoint.
Parallel work uses frozen interfaces; actual PG lanes stay serialized. No normal
measurement starts until exact source/child/env/report/proof contracts are retained.
Independent reviews disclose authored components and test/fixture contributions.
